## Known Issues to Look At

1. **No secret storage cookies** — test 8 reports empty cookies. This is likely expected since the mint-proxy workaround is commented out in the dev Dockerfile. If secret storage is needed, the mint-proxy section needs re-enabling.

2. **Welcome dialog** — The `Escape` key dismissal works but is a bit fragile. If VS Code changes the dialog or adds another one that also responds to Escape, it could dismiss the wrong thing. A more robust approach would be to find the specific close button in the dialog.

3. **Explorer selector** — Using `Control+Shift+E` works but is less explicit than clicking the actual tab. If the keyboard shortcut changes in a future VS Code version, it'll break. The `getByRole('tab', { name: /Explorer/ })` approach didn't work because the sidebar stays `hidden` with class `empty` after clicking.
